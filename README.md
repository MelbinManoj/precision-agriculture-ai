# 🌱 Precision Agriculture using AI

> AI-powered smart agriculture system using thermal cameras and drones to detect and classify crop diseases.

## 📖 Overview

A comprehensive **Smart Agriculture System** that integrates artificial intelligence, thermal cameras and drones to tackle critical tasks in farming. Using AI algorithms and image-analysis techniques, the system identifies and classifies crop diseases so farmers can intervene early, before a disease spreads across the field.

## ❓ Problem

Crop diseases are often spotted only after visible damage has spread, leading to yield loss and overuse of pesticides. Manually inspecting large fields is slow and inconsistent.

## ✨ Key Features

- Aerial field coverage using drones
- Thermal imaging to reveal plant stress invisible to the naked eye
- AI-based classification of crop diseases from captured images
- Early alerts for timely, targeted intervention

## ⚙️ How It Works

1. A drone flies over the field and captures thermal and visual images
2. Images are pre-processed (cleaning, resizing, region extraction)
3. A trained AI model analyses the images and classifies the crop condition
4. Results highlight affected areas so action can be taken early
